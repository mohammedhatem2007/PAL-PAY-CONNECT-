# **App Name**: PalPay USSD Connect

## Core Features:

- USSD Code Generation: Users can input the recipient's mobile number and the transfer amount to automatically generate the correct PalPay USSD code.
- Copy USSD Code: A button to easily copy the generated USSD code to the user's clipboard for manual dialing.
- Input Validation: Real-time validation for phone number format and amount input to ensure accuracy.
- Contextual USSD Usage Tool: An AI-powered tool that provides context-aware tips and best practices for USSD transactions based on entered details (e.g., reminding to verify recipients for large amounts).
- Theme Toggle: Allow users to switch between light and dark mode for comfortable viewing.
- RTL Layout Support: The user interface supports Right-to-Left (RTL) text direction for Arabic language users, maintaining readability and intuitive navigation.

## Style Guidelines:

- Primary color: A sophisticated, dark green (#66AD1F) symbolizing finance, growth, and reliability. This provides a strong visual anchor while being calming.
- Background color: A very light, desaturated green (#F2F5F0) creating a clean and subtle backdrop that maintains harmony with the primary color without being distracting.
- Accent color: A vibrant, clear green (#47EB47) approximately 30 degrees to the left of the primary's hue. This contrasting, energetic color will be used for interactive elements like buttons and highlights to draw user attention.
- Body and input fields will use 'Cairo' (sans-serif) for its modern, highly readable appearance in Arabic script. Headlines and prominent button text will utilize 'Tajawal' (sans-serif) for its bold, contemporary feel that enhances brand identity. Note: currently only Google Fonts are supported.
- Crisp, line-based icons in the Material Design style to complement the clean aesthetic. Icons will clearly represent their actions, such as phone, copy, and money symbols.
- A clean, form-based layout with prominent input fields and clear action buttons. Elements will be stacked vertically with ample padding and spacing to ensure readability and ease of use on both desktop and mobile, adhering to Right-to-Left (RTL) directionality.
- Subtle visual feedback for button presses and interactive elements, alongside a smooth, unobtrusive transition when switching between light and dark themes.
